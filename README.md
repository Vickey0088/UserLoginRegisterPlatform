# UserLoginRegisterPlatform
📌 User Authentication System (Task by Quantum IT Innovation)

This project is a secure User Login & Registration system built as part of a task assigned by Quantum IT Innovation. It includes features like password hashing, form validation, API structuring, and modular code architecture using best development practices.

🚀 Tech Stack

Node.js

Express.js

MongoDB (Mongoose)

bcrypt.js

dotenv

CORS

📁 Project Features

User Registration with validation

Login with secure password comparison

Passwords stored using bcrypt hashing

MongoDB Atlas integration

Clean folder structure (MVC pattern)

Environment variable support via .env

Scalable and maintainable codebase

📂 Folder Structure
config/        → Database connection  
controllers/   → Business logic  
models/        → Mongoose schemas  
routes/        → REST API routing  
middleware/    → Future authentication middlewares  
server.js      → Main server entry  

📦 API Endpoints
Method	Endpoint	Description
POST	/api/auth/register	Register new user
POST	/api/auth/login	User login
